# Pathwinder 管理器 更新记录

## v1.0.3 (2026-11-07)

### 管理器界面

- 首页列表支持点击「状态」表头排序（与名称排序互斥）
- 「说明」页重新排版：下载地址移至视频教学下方；「检查更新」改为按钮，
  点击后显示「检查中…」与进度提示，有新版本可跳转浏览器，否则提示已最新
- 检查更新兼容 GitHub API 限流：接口不可用时自动回退 `releases/latest`，
  失败提示改为中文
- 勾选「启用 Hookshot 诊断日志」时改用最大日志级别（`LogLevel=5`）
- 「设置」「说明」卡片外边距加大；设置页输入框统一为 32px 圆角样式
- 「程序详情」规则编辑框统一为相同输入框样式，位数 / 模式下拉框统一风格
- 修复规则保存后需手动点「更新指令」才生效：已受管程序的规则改动即时写入
  工作区 `Pathwinder.ini`，关闭详情页也不会丢失（写入失败时才回退显示
  「更新指令」供重试）
- 「模式切换」新增「自定义」：可为每条规则单独选择模式（规则编辑区新增
  模式下拉框）；非自定义时各规则统一跟随主选择，从自定义切回统一模式会
  先弹确认；主下拉首项更名为 `SimplePro（读回退，默认）`

### 内核

- 新增「Simple Pro（读回退）」重定向默认模式：目标路径未命中时自动用原路径重试，
  详情页「模式切换」新增该项并作为缺省推荐
- 新增外部进程与 Shell API 的路径重定向钩子：`CreateProcessW`（进程映像路径、
  命令行内绝对路径与工作目录）、`ShellExecute(A/W)`、`ShellExecuteEx(A/W)`、
  `SHCreateItemFromParsingName`、`SHOpenFolderAndSelectItems`、`SHParseDisplayName`
- 同步改写子进程环境变量块（`APPDATA` / `LOCALAPPDATA` / `USERPROFILE` / `TEMP` 等），
  「打开 / 打开所在文件夹」等 Shell 操作不再落到原路径
- 一句话解释：修复了从原始路径下拖入文件失败的问题。

## v1.0.2 (2026-11-06)

### 安装程序

- 不再弹出「正在关闭应用程序」三按钮提示：安装向导内新增页面，
  列出仍占用管理器的进程，可重试关闭或自行处理后再继续
- 安装时清理 resources 下的历史内核压缩包，并按版本选择最新包解压，
  避免安装后 payload 仍是旧内核

### 管理器界面

- 新增「设置」窗口：全局默认路径、快捷方式前缀、快捷方式恢复、日志入口
- 首页列表区改为贴边铺满；详情页「指令内容」支持鼠标选中复制
- 「说明」窗口末尾新增本更新记录卡片

### 内核

- 修复 QQ 群文件「打开 / 打开所在文件夹」无反应：
  `GetFinalPathNameByHandleW` 对已重定向的句柄改报源路径，
  `GetVolumePathNameW` 改报源盘符根，程序不再因路径不一致而中止
