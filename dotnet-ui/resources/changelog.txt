# Pathwinder 管理器 更新记录

## v1.0.7 (2026-11-26)

### 管理器界面

- 修复多进程程序（百度网盘等 Electron / Chromium 系）部分数据仍写入原目录的问题：
  「添加指令」「更新指令」时自动为安装目录下所有包含 exe 的子目录补 Hookshot 授权标记，
  确保渲染 / 宿主等子进程同样被注入并受重定向控制
- 提示：该类程序首次启动时子进程尚未注入，可能出现一次初始化报错，重启后正常
- 新登记程序的默认目标目录改为 `data\<程序名>\<规则名>`（如 `data\百度网盘\Users`）：
  每条规则使用独立子目录，不会出现「多条规则目标目录重复/嵌套」而被校验拒绝
- 规则名改为取源目录最后一级：全局默认路径设为 `C:\Users\<用户名>` 时，
  新登记程序的规则名/目标子目录为 `<用户名>`，不再固定为 `Users`
- 规则编辑时先在「原始路径」输入：自动取路径最后一级作为规则名，
  并自动生成目标路径 `data\<程序名>\<规则名>`（已手工填写的内容不会被覆盖）
- 新增每日静默检查更新：每天首次启动时自动查询一次，「有新版本」才提示，
  已是最新或网络不可用都不打扰
- 添加 / 更新 / 移除指令的确认与结果提示不再播放系统提示音（其余警告、错误提示保持不变）
- 已有程序记录保持原目标目录不变，可在详情页手动修改规则目标
- 规则校验提示改用中英文名称（源目录 / 目标目录 / 文件通配），不再显示
  `OriginDirectory`、`TargetDirectory`、`FilePattern` 等配置键名

## v1.0.6 (2026-11-25)

### 管理器界面

- 默认重定向模式改为 `Simple（严格隔离）`：新登记程序只访问目标目录，不再读到原路径上
  遗留的配置 / 登录状态；原有记录的设置保持不变，可在详情页手动切换
- 模式下拉文案更新：「Simple（严格隔离，默认）」「SimplePro（读回退，不隔离）」
- 修复已有指令在工作区 `Pathwinder.ini` 未配置 `RedirectMode` 时被自动补写成
  `SimplePro` 的问题：现在按严格 `Simple` 显示，不会悄悄关闭数据隔离

### 内核

- 读回退仅对纯读访问生效：以写 / 删除权限打开的请求不再回退到原路径，
  避免把数据写回原目录、破坏隔离

## v1.0.5 (2026-11-16)

### 管理器界面

- 「设置」新增「语言」卡片（位于第一张）：一键切换简体中文 / English，点击立即全局生效
- 「保存」记住语言选择，「取消」恢复为打开设置前的语言
- 错误提示与规则校验文案同样支持中英文
- 列宽按内容自适应：排序、导入、删除后重新测量，长名称与排序箭头完整显示
- 列表滚动条修改
- 关闭「详情」只刷新被修改的行，列表保持当前滚动位置

## v1.0.4 (2026-11-14)

### 管理器界面

- 启动时检测 Microsoft Visual C++ 2015-2022 运行库（x64 / x86）：缺失时弹窗提示，
  「是」打开对应位数的官方下载地址，「否」不再提示（可在「设置」中重新开启），
  「取消」本次跳过
- 「设置」新增「外观」卡片：一键切换深色 / 浅色主题（含窗口标题栏），点击立即生效；
  点「保存」保存选择，点「取消」恢复为打开设置前的主题
- 「设置」的「确定」按钮改为「保存」：设置项没有改动时按钮为禁用状态
- 「全局默认路径」只在点「保存」时写入配置并生效，选中目录不再立即保存
- 「分享」「日志」入口移入「说明」窗口的「关于」卡片，与「检查更新」并排；设置页不再保留日志卡片
- 「说明」窗口的更新记录随主题自动换色（深色主题下自动使用浅色文字）
- 「管理员启动」按钮改为权限切换：按钮直接显示当前权限
  （「当前权限：管理员」/「当前权限：普通用户」），点击即切换到另一种权限并重启
- 修复系统关闭 UAC 时无法切换回管理员的问题：切到普通权限后，原管理员进程隐藏为
  「提权中转」，点击切回时由中转进程以管理员令牌启动新实例（普通权限实例关闭后中转自动退出）
- 更新说明：修复微信 4.2.0.52 更新后笔记 / 收藏卡片打不开的问题

### 内核

- 子进程位于重定向目标目录时自动补建 Hookshot 授权标记（`<exe>.hookshot`）：
  应用自更新重建插件目录后无需人工补文件，不会再出现
  `Not authorized to inject the new process`

## v1.0.3 (2026-11-07)

### 管理器界面

- 首页列表支持点击「状态」表头排序（与名称排序互斥）
- 「说明」页重新排版：下载地址移至视频教学下方；「检查更新」改为按钮，
  点击后显示「检查中…」与进度提示，有新版本可跳转浏览器，否则提示已最新
- 检查更新兼容 GitHub API 限流：接口不可用时自动回退 `releases/latest`，
  失败提示改为中文
- 勾选「启用 Hookshot 诊断日志」时改用最大日志级别（`LogLevel=5`）
- 「设置」「说明」卡片外边距加大；设置页输入框统一为 32px 圆角样式
- 「程序详情」规则编辑框统一为相同输入框样式，位数 / 模式下拉框统一风格
- 修复规则保存后需手动点「更新指令」才生效：已受管程序的规则改动即时写入
  工作区 `Pathwinder.ini`，关闭详情页也不会丢失（写入失败时才回退显示
  「更新指令」供重试）
- 「模式切换」新增「自定义」：可为每条规则单独选择模式（规则编辑区新增
  模式下拉框）；非自定义时各规则统一跟随主选择，从自定义切回统一模式会
  先弹确认；主下拉首项更名为 `SimplePro（读回退，默认）`

### 内核

- 新增「Simple Pro（读回退）」重定向默认模式：目标路径未命中时自动用原路径重试，
  详情页「模式切换」新增该项并作为缺省推荐
- 新增外部进程与 Shell API 的路径重定向钩子：`CreateProcessW`（进程映像路径、
  命令行内绝对路径与工作目录）、`ShellExecute(A/W)`、`ShellExecuteEx(A/W)`、
  `SHCreateItemFromParsingName`、`SHOpenFolderAndSelectItems`、`SHParseDisplayName`
- 同步改写子进程环境变量块（`APPDATA` / `LOCALAPPDATA` / `USERPROFILE` / `TEMP` 等），
  「打开 / 打开所在文件夹」等 Shell 操作不再落到原路径
- 一句话解释：修复了从原始路径下拖入文件失败的问题。

## v1.0.2 (2026-11-06)

### 安装程序

- 不再弹出「正在关闭应用程序」三按钮提示：安装向导内新增页面，
  列出仍占用管理器的进程，可重试关闭或自行处理后再继续
- 安装时清理 resources 下的历史内核压缩包，并按版本选择最新包解压，
  避免安装后 payload 仍是旧内核

### 管理器界面

- 新增「设置」窗口：全局默认路径、快捷方式前缀、快捷方式恢复、日志入口
- 首页列表区改为贴边铺满；详情页「指令内容」支持鼠标选中复制
- 「说明」窗口末尾新增本更新记录卡片

### 内核

- 修复 QQ 群文件「打开 / 打开所在文件夹」无反应：
  `GetFinalPathNameByHandleW` 对已重定向的句柄改报源路径，
  `GetVolumePathNameW` 改报源盘符根，程序不再因路径不一致而中止
